# Changelog

All notable changes to the AIVory Monitor Bun Agent will be documented in this file.

This project adheres to [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-02-16

### Added
- Automatic capture of uncaught exceptions and unhandled rejections
- Manual exception capture API
- Native Bun WebSocket transport
- Preload support for zero-code initialization
- Configurable sampling rate and capture depth
- Environment variable configuration
- Bun 1.0+ support
